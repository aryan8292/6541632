# PriceTracker Pro

Vercel-ready Vite frontend with an Edge/API proxy.

## Deploy

1. Push this repository to GitHub.
2. Import it into Vercel.
3. Keep **Root Directory** at the repository root.
4. Vercel will run `npm run build` and publish `dist`.
5. Set `BACKEND_ORIGIN` and `ALLOWED_ORIGINS` in Vercel Environment Variables.

## Important

The supplied source did not include the original ~1,000-line CSS block. The project therefore contains a minimal CSS fallback in `src/styles/` so the build has real stylesheet files. Replace those files with the original styles if you have them.

## Build layout

- `index.html` — Vite entry point
- `src/` — application source
- `public/` — static assets
- `api/proxy.js` — Vercel API function
- `dist/` — generated by Vite; do not commit it
